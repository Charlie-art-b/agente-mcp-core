# Documento de ejemplo para probar el RAG

> Este archivo es solo contenido de prueba para validar que el motor de
> búsqueda semántica funciona correctamente. No es un módulo de negocio.
> Reemplazá o eliminá este contenido cuando definas qué base de
> conocimiento real vas a usar.

## Horario de atención

El horario de atención general es de lunes a viernes, de 8:00 a.m. a
5:00 p.m. Los sábados se atiende de 8:00 a.m. a 12:00 p.m. Los domingos
no hay atención.

## Política de cancelación

Las cancelaciones se pueden hacer hasta 24 horas antes sin ningún costo.
Si se cancela con menos de 24 horas de anticipación, se cobra un 50% del
valor del servicio como penalización.

## Métodos de pago aceptados

Se aceptan pagos en efectivo, tarjeta de crédito, tarjeta de débito, y
transferencia SINPE móvil. No se aceptan cheques.

## Ubicación

El local está ubicado a 200 metros del parque central, en el segundo
piso de un edificio comercial. Hay parqueo disponible para clientes.
